# 建设与规格

空白工程先从整体需求确认用户、核心业务、应用范围、验收、部署约束与技术栈，再确定目录职责及环境。只创建已确定且需要的目录；不复制试点的四应用结构或历史版本。

既有工程先沿用稳定选型。技术调整记录原因、影响、迁移和验证，重要选择取得用户确认后实施。

正式功能关联工程指定工单。新能力、业务规则、跨模块或 API 变化使用 OpenSpec：在 `openspec/changes/<change>/` 保存 proposal、design、tasks 和 specs；各产物分工，不在工单和另一套 plans 目录复制完整正文。工单保留诉求、验收与链接。

恢复已约定行为的局部 Bug 转实施流程，保留复现/修复/回归证据；发现规范本身需要变化才升级为规格变更。

新工程 Gitea/Drone 按确认技术栈配置 Tag 构建与产物，通过已授权的测试 Tag 验证后才记为接通。工程配置中用户明确确认的既有 Drone 集成直接沿用，不重新审计该流水线。

## 关键疑问先澄清

本规则贯穿接入、文档、原型与开发，不只用于新工程。

1. **尽早识别**：发现会影响范围、业务规则、权限、数据口径、验收或重要技术选择的疑问，先查当前对话、工单及适用规范。已有明确答案直接沿用；仍无法判断时，在定稿相关规格或开展依赖它的开发前向用户确认，不等到整套文档或代码完成才问。
2. **集中提问**：将当前已发现且需用户决定的问题按依赖关系归并，每题给出推荐答案、理由及主要影响；有合理备选时一并列出，避免逐条碎片追问。需要核实的事实提供推荐核实路径，不猜测事实作为答案。不要求一次预见所有后续问题；新增疑问发现后及时提出。遵循现有规范且不改变外部行为、范围或验收的命名、文件内组织等实现细节由 Agent 决定。
3. **等待期间**：可以只读调查、建立工单、记录待确认项、准备明确标为候选的方案或原型；也可继续已经授权且不依赖该决定的工作。未确认的假设不得写成正式结论，不定稿相关规格、不实施依赖它的业务代码。满足下述默认选择条件时，可按用户预先授权采用推荐方案；其他问题继续待确认。工单、Figma、测试或安全流程要求明确批准时保留该门槛；超时不作为用户已批准的证据。
4. **决定后落实**：在现有工单或决策入口记录答案、范围及依据，区分“用户明确确认”和“按预授权超时采用推荐”，更新相关文档后继续，不新增重复报告、不重复询问同一已确认事项。已有文档不构成业务规则已获批准的证据。
5. **中途出现疑问**：暂停受影响部分，说明未知项及影响并澄清；保留独立工作进度。若新结论改变原有范围或已批准原型，按对应确认流程处理，不能用前一次确认覆盖新的决定。

## 提问推荐与三分钟默认选择

用户明确采用本策略时，沿用已有授权，不逐题询问是否启用；仅安装 Skill 不构成授权。普通问题在发送时说明推荐选项和超时行为，用户可随时指定“这题必须等我确认”或暂停，当前明确指令优先。

- **适用范围**：已授权任务范围内、有依据且可逆的需求方案、展示方式与实现选择。每题先判断是否允许默认选择，再明确展示推荐答案、理由及主要影响；不能隐藏默认选项或事后补推荐。
- **必须等待的事项**：Figma 原型验收、用户自测通过、另需授权的重要技术变更或高风险操作，以及未授权的范围/权限扩大、发布、真实数据破坏和宿主审批。可以给出建议，但明确告知该题不适用超时选择；推荐“通过”不能代替验收或授权。缺少账号、环境事实、业务数据等实际信息时，推荐核实路径，不能计时后假定事实成立。已有有效操作授权仍直接沿用，不新增确认。
- **真实计时**：通过宿主可用的异步提问通道发送后，记录每题的发送时间、推荐内容和适用性；截止时间为发送后 180 秒。使用可靠时间来源核对已过时长，不按工具调用次数、模型推测或预选状态计时。等待时继续独立工作；需要等待工具时每次不超过 60 秒，并响应新消息。
- **到期处理**：执行前再次检查回复、暂停或方案变化。仅对已明确告知默认行为、180 秒已满且未收到答复的适用题，采用原推荐并简短告知用户，记录原因后继续依赖流程。用户已明确答复则采用其选择；含糊答复继续澄清，不按未回复处理。部分回答只处理已解决的题，其他题分别保留计时或等待状态。仍有必要的必答项时，不开展依赖它的工作。
- **变化与续接**：用户要求等待、否定推荐但未选替代，或出现使推荐失效的新信息时停止该题自动选择；修改推荐后重新展示并计时，不能沿用旧倒计时。恢复会话时先检查新消息和可核验的原时间/问题记录；无法证明已满 180 秒时不猜测到期。当前宿主不能持续执行或可靠计时时说明限制并标为待续，不宣称已安排后台自动继续。

普通题的提示示例：“推荐 A，因为……；本题可按已授权默认策略处理，3 分钟内未回复将采用 A 继续。你也可以指定必须等你确认。” 必答题给出建议及所需证据，并说明继续等待明确答复。上述计时是当前会话的执行流程，不自动创建后台调度或跨会话唤醒。
