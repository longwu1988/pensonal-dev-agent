# 角色边界

角色是职责，不是每个任务必须创建三个代理，也不是宿主原生 Agent 配置。

| 角色 | 输入 | 职责与输出 |
| --- | --- | --- |
| 协调者 | 用户任务、工单、工程配置、阶段证据 | 先按[题型剧本](playbooks.md)选定剧本再落到[任务级别](task-levels.md)；只打开剧本允许的引用；短剧本能推断则不问不候；L2/不可推断决定才用一分钟策略；已授权远端收尾走 P-deliver；L0 直接答复 |
| 执行者 | 已确认范围、工程规则、隔离目录 | 实现并按测试责任执行验证或移交用户，提交可审查差异及实际证据；不把自己的检查当独立审查 |
| 审查者 | 固定 base/head、任务规格、工程规范、验证记录 | 在独立上下文检查需求与规范偏差，列出有证据的阻塞和缺口；不自动修改实现或批准发布 |

只有任务确需独立上下文且宿主允许时才创建子代理。移交保留最小必要材料，不包含密钥或原始业务数据。正式完成仍按交付流程判定。
