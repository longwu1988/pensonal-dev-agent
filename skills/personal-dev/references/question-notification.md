# 确认问题的本地语音提醒

向用户发出需要答复的确认问题后，默认在用户使用的本机播放一次固定提示：“有问题待确认，请及时处理”。语音只提醒有待办，内容不含问题正文、账号或业务信息；实际选项与推荐仍通过文字发送。

## 触发与顺序

1. 先核对用户/工程的静音选择。实际发送问题后，记录该批问题的发送时间、推荐及范围，再播放；不能在问题尚未发出时声称已提醒。
2. 每批问题只播放一次，多题合并发送共用一次提醒。将“已尝试提醒/结果”记在现有任务记录；同一批等待、轮询、重试和会话恢复不重复播放。真正重新提出的新问题或用户要求再提醒时才播放下一次。
3. 执行以下已安装入口。它只读取随包预生成的本地 WAV，并调用播放器；不联网、不调用语音生成服务、不在提问时临时生成语音。命令最多等待播放器 12 秒，不另开后台常驻进程。

```sh
python3 .agents/skills/personal-dev/scripts/pda.py notify-question --project .
```

源码维护时使用 `python3 scripts/pda.py notify-question --project .`。当前实现支持 macOS 的 `/usr/bin/afplay`；其他平台或 SSH 会话返回 unavailable。远程开发、容器或服务器中的播放不等于用户本机收到提醒，优先使用已授权的用户本机执行工具；没有可用入口时保留文字提醒，不擅自安装播放器或修改系统音量。

仅安装 Skill、缺少运行时但含完整音频资源时，可在用户 macOS 本机直接执行 `afplay .agents/skills/personal-dev/assets/question-pending.wav`，同样每批一次；没有文件时报告缺口，不即时合成或下载未知音频。完整安装的播放器先核对固定资源 SHA256，缺失、篡改、播放失败或超时返回 unavailable，提问仍然有效。`playback_finished` 只表示播放器正常退出，不证明用户听见或确认。

## 与倒计时、等待及静音的关系

语音和[一分钟默认选择](planning.md#提问推荐与一分钟默认选择)互相独立：倒计时以问题实际发送时间为起点，播放不延后或重置截止时间；播放失败不跳过等待，也不意味着可以提前采用推荐。

用户要求“必须等我回复”、关闭默认选择或必需审批的题，仍可播放一次，但继续保持等待。用户说“关闭语音提醒/静音”时，只关闭相应范围的声音，不关闭默认选择；说“恢复语音提醒”后，仅对以后新发出的问题恢复提醒。工程级选择保存在工程自己的 AGENTS.md 非受管区域或已有规则中，任务级选择保存在当前任务记录，不新增 project.json 字段。范围不明确时先对当前待确认问题静音并核对范围。

用户停止任务或队列后不继续提示新问题、不重播旧题；已发出的短音频可能已在播放，不以提醒为由恢复任务。普通进度、最终答复、无需用户决定的咨询及安装升级过程不播放。语音资源来自[固定音频说明](../assets/README.md)，安装和更新只复制文件，不自动试听。
