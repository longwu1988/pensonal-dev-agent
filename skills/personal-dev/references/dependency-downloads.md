# 依赖下载与镜像

适用于工程初始化、日常开发、测试准备及 CI/Docker 构建中的包、工具链和镜像下载。国内网络环境下载公共依赖时，优先使用可信、可用且同步所需版本的国内镜像，减少下载超时；用户指定来源、工程强制源和私有仓库约定优先。其他网络环境按实际连通性选择，不机械套用国内源。

1. **先读配置**：检查包管理器、锁文件、源配置及 CI/Docker 构建文件。保留既有私有包路由、认证和版本约束；公共包换源不覆盖 npm scope registry、Python 私有索引等专用配置，也不把私有包名或凭据发送到公共镜像。
2. **选择可信源**：优先使用工程已验证的国内镜像；没有现成配置时，从维护方官方文档核实国内镜像地址、适用生态与使用方式，再检查所需包/版本可用性。npm/pnpm/yarn、pip/uv、系统包、工具链二进制和容器镜像分别配置，不能假定换 npm 或 PyPI 源会加速全部下载。镜像站不支持的资源使用官方渠道，不使用来源不明的代理。
3. **控制作用域**：优先命令参数或进程环境变量；需要复用时使用项目级配置或项目 CI/Docker 构建参数，并在现有环境说明记录来源和回退方式。未经明确授权不修改用户全局源、系统源或 Docker daemon，不重启共享服务。认证信息通过受控环境传入，不写进可提交配置或镜像层。
4. **失败回退**：镜像连接失败、缺少所需版本或同步滞后时，先确认是来源问题，在既有来源限制内切换另一可信国内镜像或官方源，简要记录原因；有界重试，仍不可用则报告阻碍。私有包只在批准的私有来源内处理，不回退公共源。校验不一致时丢弃异常下载并核实官方产物，不关闭 TLS、签名或哈希校验，不通过降低版本掩盖问题。
5. **保持可复现**：换源不改变依赖意图，保留锁定版本、完整性哈希及容器 digest 校验。锁文件内嵌下载地址时先核对实际请求，不能声称配置已覆盖，也不盲目批量替换或删除锁文件。确需调整时使用对应包管理器并审查差异；多个 Python 索引不视为有顺序保证的自动回退，保留明确的包与来源绑定。
6. **验证结果**：在实际执行环境检查来源是否生效、依赖是否按锁定版本安装，执行任务所需检查。CI 或容器未运行时如实标记未验证；不能以本机下载成功代替构建环境验证。任务仅要求完善规则时，不顺带安装包或修改机器源配置。
