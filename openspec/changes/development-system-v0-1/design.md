# 第一版架构与适配设计

## Context

个人仓库保存通用方法，业务工程声明技术栈、应用目录、验证入口、工单系统和授权范围。第一版从 zkxw 试点，但必须用干净工程证明可以独立复用。

## Goals / Non-Goals

- 统一阶段交接和完成证据，减少重复访谈、重复计划与规则复制。
- 保持根规则短小，通过明确触发条件查阅专题。
- 面向 Codex、Cursor 验证发现、调用、权限边界和结果。
- 本次交付设计文档；运行能力、第三方内容引入和定时任务分别按里程碑交付。

## Decisions

### 1. 用职责组织 Agent，用任务流程组织 Skill

| 职责 | 输入 | 输出与完成条件 |
| --- | --- | --- |
| 协调者 | 用户任务、工单、工程配置、当前状态 | 选择任务等级、主流程和所需上下文；移交可执行的验收条件 |
| 执行者 | 已确认任务、规则、目标分支、隔离工作区 | 实现、相关验证、差异与剩余限制；留下可复查提交 |
| 审查者 | 固定提交范围、工单/规格、工程规则和验证证据 | 区分需求偏差、规范问题和验证缺口；说明阻塞项 |

这些是工具无关的职责，不等于每次创建三个子代理。重要业务变更需要独立审查上下文；宿主不支持时采用人工或独立会话，不把执行者自查标记为独立审查。Web、后端和移动差异先由各端规则和技能承载。

### 2. 每一阶段只采用一个主流程

| 阶段 | 主能力来源 | 权威产物 |
| --- | --- | --- |
| 澄清、领域与模块设计 | Matt Pocock | 工单验收条件、OpenSpec 规格与设计 |
| 界面设计 | Figma MCP | 工单/规格引用的具体文件和节点 |
| 实现、调试、测试与审查 | Superpowers | 代码、可追溯的验证与审查证据 |
| 规格变更与归档 | OpenSpec | 活动变更及完成后归档的长期规范 |
| 复盘与提炼 | Matt Pocock 方法及本体系复盘流程 | 审核后的知识或能力改进 |

第一版按验证案例精选所需技能，而不是让全部已安装技能自动参与。已完成的澄清证据应移交实现阶段，避免再次触发完整访谈。

### 3. 对冲突做实际适配

安装前检查上游技能的触发方式、宿主声明、文件输出和依赖。`grilling` 与 `brainstorming` 的访谈方式、两套调试入口、两套 TDD 入口，以及 `docs/superpowers/` 和工单内完整规格等输出，均需明确选用或转换。

优先通过上游配置扩展；确需改编时保留固定来源、许可和改动原因，并用行为案例验证。单纯写一句“本规则覆盖上游”不能消除实际冲突，也不能覆盖宿主指令或用户授权。

### 4. 工程配置承担环境差异

初始化读取已有事实，再询问无法推断的决策。配置至少声明应用映射、技术栈决策入口、工单仓库、集成分支、验证命令与环境条件、worktree 策略、Figma 引用、构建发布约定、允许的远端动作和复盘位置。

业务仓库地址、`V2.0`、实际命令、账号与环境路径属于工程配置，不作为通用技能默认值。配置保存密钥来源的说明或引用，不保存密钥值。每次能力调用只加载相关配置。

### 5. 结构按能力逐步建立

| 未来位置 | 何时创建 |
| --- | --- |
| `agents/` | 有需要跨工具复用且边界明确的角色定义 |
| `skills/` | 有可调用的流程及代表性行为案例 |
| `adapters/` | 有宿主差异的生成、转换或检查逻辑 |
| `templates/` | 有已验证的工程初始化输入与模板 |
| `profiles/` | 有版本固定、已验证的能力组合 |

当前仅创建 OpenSpec 设计材料，不生成上述空目录，也不把个人仓库自身的 AGENTS 分发给业务工程。

## Risks / Trade-offs

- 分发能力会受到上游版本变化影响：固定来源并主动升级，验证变化后的路由与输出。
- 多工具能力不等价：按工具记录验收；子代理、原生 worktree 或 MCP 不可用时明确降级。
- 本机夜间执行受运行环境影响：按 [复盘规范](specs/knowledge-retrospective/spec.md) 记录进度和缺口，不依赖未验证的自动补跑行为。
- worktree 仅隔离文件：测试库、端口与凭据需由工程独立配置。

## Migration Plan

已有工程采用增量接入和目录映射，保留现有规则及用户改动。先展示拟管理的文件与差异，再在已授权范围内应用；无法无损合并的冲突交给用户决定。

zkxw 的既有技术栈和 Drone 配置保持原有约定。新增能力先验证后推广，不能因为存在某个配置文件便宣称完整初始化、权限连接或自动化已经成功。
