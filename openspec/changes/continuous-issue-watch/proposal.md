# 持续处理未来新增工单

## Why

当前队列为空时退出，用户希望明确开启后继续处理未来新增工单，直到主动停止。

## What Changes

- 增加独立的持续授权状态、宿主计划绑定与有间隔的检查入口，默认每 5 分钟处理 ai-ready。
- 使用 Codex 当前会话原生 heartbeat 指引；停止撤销旧唤醒，沿用串行队列和交付规则。
- 分发协议升为 3，旧协议使用完整源码迁移，保留工程配置和已有进度。

## Impact

涉及 CLI、队列启动竞态保护、运行时分发、Skill 入口及使用指南。安装不自动开启真实工程；真实宿主连续运行仍待试点。详见[设计](design.md)和[规范](specs/continuous-issue-watch/spec.md)。
